# TTS-Bareng-Web

Official landing page, pre-registration portal, and Apple App Store compliance legal center for **TTS Bareng (Teka Teki Silang Bareng)**.

## Fitur & Halaman
- **Landing Page Modern**: Showcase gameplay Mabar Co-op, 1v1 Tug-of-War, dan 12 Alam Tematik Nusantara.
- **Pusat Kepatuhan Legal Apple (App Store Review Guidelines 5.1.1)**:
  - Kebijakan Privasi Pengguna (`#privacy`)
  - Syarat & Ketentuan Layanan / EULA (`#terms`)
  - Atribusi Resmi Kosakata KBBI (`#kbbi`)
- **Pre-Registrasi VIP**: Formulir pre-order & early-access terintegrasi.

## Stack Teknologi
- React 18 + TypeScript
- Vite 6
- Tailwind CSS 3
- Framer Motion 12
- Lucide React

## Panduan Menjalankan

```bash
# Install dependensi
npm install

# Jalankan server pengembangan
npm run dev

# Kompilasi build produksi
npm run build
```
